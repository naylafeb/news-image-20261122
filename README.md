A front-page image summing up Sunday 22 November 2026 in 45 stories across 7 regions plus a day-in-numbers box: COP31 collapses in Antalya with no deal, Iran strikes Bahrain, the Trump–Xi–Putin summit in Shenzhen, the AI sell-off on Wall Street, and a magnitude 6.7 quake in Peru. Every story was checked against the day's reporting; the image is drawn from `stories.json`.

Run it with:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) copies `entry.png` to `/output/entry.png`.
